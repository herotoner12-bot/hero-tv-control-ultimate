# HERO TV CONTROL ULTIMATE

تطبيق Android (Kotlin + Jetpack Compose) للتحكم بالتلفزيون عبر Wi-Fi محلياً. واجهة عربية RTL بتصميم أسود وأزرق.

## تقرير الحالة (الإصدار 0.3.0)

> **لم يُجرَّب شيء من هذه الميزات على جهاز حقيقي، ولم يُجمَّع المشروع بعد.** بيئة التطوير التي كُتب فيها المشروع لا تصل إلى
> مستودعات Google وMaven، فلم يكن ممكناً بناء الـ APK أو اختباره. فُحص بناء الجملة فقط بمترجم Kotlin. أول بناء حقيقي سيكون على GitHub Actions،
> وقد يظهر فيه خطأ تجميع يُصلَح بعد قراءة سجل البناء.

## القيود التقنية (بوضوح)
- **Gamepad**: ADB لا يُنشئ جهاز Gamepad حقيقياً على التلفزيون. التطبيق يرسل أزرار Gamepad (`input gamepad keyevent`). الألعاب التي تقبل أزرار الريموت أو الـ Gamepad الرقمي قد تعمل، أما الألعاب التي تتطلب عصا تناظرية دقيقة أو جهازاً فعلياً فقد لا تستجيب.
- **العصا التناظرية**: تُرسل أحداث `input joystick motionevent` وهي تجريبية؛ قد يتجاهلها التلفزيون كلياً. الوضع الرقمي هو الموصى به.
- **الضغط المستمر**: ADB لا يدعم "إبقاء الزر مضغوطاً"؛ يُحاكى بتكرار الضغطة كل 130 ملّي ثانية.
- **التأخير**: كل أمر يمر عبر `input` على التلفزيون، فالاستجابة أبطأ من يد حقيقية.
- **لوحة المفاتيح**: `input text` لا يدعم الأحرف العربية.
- **أيقونات التطبيقات**: ADB لا يعيدها، فيُعرض الحرف الأول من اسم التطبيق. ولا يمكن معرفة الألعاب تلقائياً؛ تُعلَّم يدوياً.
- **اللغة**: العربية فقط (لا توجد ترجمات أخرى).
- بعض التلفزيونات تخفي «التصحيح اللاسلكي»؛ حينها جرّب «تصحيح USB/الشبكة» ثم «اتصال فقط».

## بنية المشروع
- `app/` تطبيق Compose.
- `libadb/` مكتبة libadb-android v3.1.1 (MuntashirAkon) منسوخة كمصدر، بترخيص Apache-2.0 (انظر `libadb/COPYING`). تعتمد على `spake2-android` من JitPack.
- `legacy-termux/` نسخة مشروع Termux القديم كما هو (خطة احتياطية، لا يعتمد عليها التطبيق).

## الأمان
- الاتصال محلي على شبكة Wi-Fi فقط، ولا توجد أي طلبات إلى الإنترنت.
- مفتاح ADB الخاص مشفّر بمفتاح AES داخل Android Keystore.
- الأوامر المرسلة محددة بقائمة بيضاء؛ لا توجد أوامر Shell عشوائية.
- رمز الاقتران لا يُحفظ.

## بناء الـ APK من الهاتف (GitHub Actions)
داخل مجلد المشروع في Termux (الذي أنشأت منه المستودع سابقاً):
```
cd ~/storage/downloads
unzip -o hero-tv-control-ultimate.zip -d ~/
cd ~/hero-tv-control-ultimate
rm -f app/src/main/java/com/herotoner/herotv/ui/screens/PlaceholderScreen.kt
git add -A
git commit -m "Phase 3: pairing, remote, gamepad, apps, settings"
git push
```
ثم افتح Actions في مستودع `hero-tv-control-ultimate` وانتظر **Build APK**، ونزّل الملف المرفق `HERO-TV-CONTROL-ULTIMATE-debug` وثبّت الـ APK.

إن فشل البناء، أرسل لقطة للسطور التي تحت `FAILURE:` أو `error:` في سجل Actions.

## أول اختبار مقترح على الجهاز
1. على التلفزيون فعّل خيارات المطوّر ثم «التصحيح اللاسلكي» ← «اقتران جهاز برمز الاقتران».
2. في التطبيق: الرئيسية ← اقتران التلفزيون، واكتب الرمز والمنفذ (أو اضغط «استخدام» على النافذة المكتشفة)، ثم «اقتران واتصال». وافق على نافذة السماح على التلفزيون.
3. جرّب الريموت، ثم التطبيقات، ثم يد الألعاب مع لعبة تقبل أزرار الريموت.
