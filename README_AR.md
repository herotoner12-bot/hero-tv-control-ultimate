# HERO TV CONTROL ULTIMATE

تطبيق Android (Kotlin + Jetpack Compose) للتحكم بالتلفزيون عبر Wi-Fi محلياً. الواجهة عربية RTL بتصميم أسود وأزرق.

## حالة المراحل

| المرحلة | الحالة |
|---|---|
| 1. فحص المشروع القديم + نسخة احتياطية | مكتملة |
| 2. الهيكل الأساسي للتطبيق | **مكتوبة، لم تُجمَّع بعد** (تُبنى أول مرة على GitHub Actions) |
| 3. الاقتران + الريموت الفعلي | لم تبدأ |
| 4. Gamepad | لم تبدأ |
| 5. التطبيقات والألعاب | لم تبدأ |
| 6. الخدمة بالخلفية | لم تبدأ |
| 7. الاختبار الكامل | لم تبدأ |

## ما الموجود في المرحلة الثانية
- مشروع Gradle كامل (AGP 8.11.1، Kotlin 2.2.0، compileSdk/targetSdk 36، minSdk 26).
- ثيم أسود وأزرق، واجهة RTL مفروضة، أيقونة التطبيق، واسم التطبيق.
- الصفحة الرئيسية، وصفحة الريموت (واجهة فقط)، وشريط تنقل سفلي.
- صفحات الاقتران والألعاب والتطبيقات والإعدادات شاشات مؤقتة تذكر المرحلة التي ستُبنى فيها.
- `TvCommand`: قائمة الأوامر المسموحة الـ12 بنفس أرقام مشروع Termux القديم.
- `legacy-termux/`: نسخة من مشروع Termux القديم كما هو، كخطة احتياطية.

## ما لا يعمل بعد (بوضوح)
- لا يوجد اتصال بالتلفزيون: حالة الاتصال دائماً «غير متصل»، وأزرار الريموت تعرض رسالة بدل إرسال أمر.
- لا يوجد اقتران ولا بحث عن أجهزة ولا Gamepad ولا قائمة تطبيقات.
- لم يُختبر شيء على جهاز حقيقي، ولم يُجرَّب البناء بعد.

## بناء الـ APK من الهاتف (GitHub Actions)
1. أنشئ مستودعاً جديداً على GitHub (يفضّل خاصاً).
2. في Termux:
   ```
   cd ~/storage/downloads
   unzip hero-tv-control-ultimate.zip -d ~/hero-tv-control-ultimate
   cd ~/hero-tv-control-ultimate
   git init -b main
   git add .
   git commit -m "HERO TV CONTROL ULTIMATE - phase 2"
   git remote add origin https://github.com/<اسمك>/<المستودع>.git
   git push -u origin main
   ```
3. افتح تبويب Actions في المستودع وانتظر اكتمال **Build APK**، أو شغّله يدوياً من Run workflow.
4. من صفحة التشغيل نزّل الملف المرفق `HERO-TV-CONTROL-ULTIMATE-debug`، وفك ضغطه لتجد ملف APK، ثم ثبّته (فعّل «التثبيت من مصادر غير معروفة» إن طُلب).

ملاحظة: نسخة debug موقّعة تلقائياً بمفتاح debug وتُثبَّت مباشرة. توقيع نسخة release يُضاف لاحقاً.

إن فشل البناء، أرسل لي نص الخطأ من سجل Actions وأصلحه قبل الانتقال إلى المرحلة الثالثة.
